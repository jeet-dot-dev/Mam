# 💜 Happy Anniversary — Our Story

A romantic single-page website celebrating an anniversary.  
Made with love, featuring the soundtrack **d4vd — Here With Me** and lovely interactive animations.

## ✨ Features

- 🎵 **Music** — Background soundtrack with smooth playback controls
- 📸 **Photos** — 15 memorable photos in elegant grids with shine and lightbox preview
- 🎬 **Videos** — 3 videos (nature, dance) with autoplay on scroll
- ⏱ **Timer** — Real-time counter of days, hours, minutes, and seconds spent together
- 🎡 **Spin to Win Wheel** — Romantic lucky prize wheel with 7 surprises, sound chimes, and celebration popup
- 💖 **Interactive Animations**:
  - Click — bursting hearts & ripples
  - Double click — sweet love message popups
  - Long press — love explosion meter
  - Heart cursor trail with glowing sparkles
  - Falling sakura petals & twinkling night sky stars
  - 3D card tilt effects on hover
  - Floating background hearts drawn on canvas
- 📱 **Responsive Design** — Optimized for mobile, tablet, and desktop
- 🤳 **Shake on Mobile** — Device motion trigger for love explosion!

## 🛠 Tech Stack

- HTML5
- CSS3 (Animations, Gradients, Glassmorphism)
- JavaScript (Vanilla JS, Canvas API)
- Zero external UI libraries
